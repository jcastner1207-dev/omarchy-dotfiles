# Omarchy Dotfiles

Configuration for my Omarchy Linux setup.

## Key Bindings

- **Super+Return**: Opens tmux (Omarchy Terminal)
- **Super+Shift+R**: Reloads Hyprland with notifications

## Repository Structure

```
configs/
├── hyprland/     # Hyprland Wayland configs
└── omarchy/      # Omarchy shell & hooks
```
